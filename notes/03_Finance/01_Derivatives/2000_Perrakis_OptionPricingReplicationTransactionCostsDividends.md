## 1. 研究質問と結論

株式取引に比例的な売買コストがあり、満期前に既知の配当があるとき、アメリカン・コールの買い気配・売り気配と完全ヘッジ・ポートフォリオをどう求めるかを問う。

結論は、取引コスト下では一意な無摩擦価格ではなく、マーケットメーカーのロング・ショートそれぞれを確実に履行できる **bid/askの価格帯** と対応するsuper-replicating portfolioが自然な対象になる、というものだ。配当落ち日には早期行使を一意に決められない株価区間が現れ得る。そこでは保有者の選好・直前の株価遷移が効き、無摩擦モデルの単一exercise boundaryは崩れる。

## 2. 中核アイデア

無摩擦二項モデルでは、株式と債券の動的売買で満期ペイオフを複製し、その初期費用が唯一のオプション価格となる。取引コストがあると、株式を買う価格と売る価格が異なるため、ロングを履行するためのヘッジとショートを履行するためのヘッジは非対称になる。

株価のbid/askを (S_t^b\) と (S_t^a\) とし、コールの満期ペイオフを

```math
H_T=(S_T-K)^+
```

とする。売り手側のaskは、全状態で

```math
V_T^{\mathrm{ask}} \ge H_T
```

を満たす自己金融ポートフォリオの最小初期費用として、買い手側のbidは反対ポジションを安全に履行できる最大受取額として定義される。したがって、無摩擦の等式複製は不等式によるsuper-replicationへ置き換わる。

既知の配当 (D\) が配当落ち日に支払われると、早期行使と継続の比較は、行使価値 (S_d-K\) と取引コストを含む継続価値の比較になる。著者らの重要な点は、閾値が一点ではなく概念的に

```math
S_d \in [S_d^{L}, S_d^{U}]
```

という区間になり得ることだ。区間の下では継続、上では即時行使だが、その内部では直前のup/down状態を含む保有者側の状況に依存し得る。

## 3. モデルと設計

- 多期間二項株価モデルに、株式の比例的取引コストと満期前の既知配当を導入する。
- マーケットメーカーがcallを売った場合と買った場合を別々に考え、各ポジションを全ノードで安全に履行するportfolioを後方帰納で求める。
- 単一配当についてask・bidのrecursionと行使境界を示し、複数配当へ拡張する。
- 数値例で、満期、配当、取引コストが価格帯と再調整に与える影響を示す。

これは市場データを使う実証論文ではなく、無摩擦複製を取引コスト下の頑健なヘッジ問題へ置き換える理論研究である。

## 4. 主要な含意

1. **価格は区間になる**: 原資産のbid/askと再ヘッジ費用が、オプションのbid/ask wedgeを生む。
2. **配当があるアメリカン・コールは特別に難しい**: 無摩擦でも早期行使を考える必要があり、取引コストは行使判断を状態依存の区間へ広げる。
3. **完全複製と最適再調整は同義ではない**: 毎期のexact replicationは安全だが、再調整コストを考えると、余剰を残すsuper-replicationが安い場合がある。
4. **売り手と買い手を対称に扱えない**: 買い・売りの株式コストが異なるため、単一の理論値を中央に置いて両側へ一定スプレッドを足すだけでは足りない。

## 5. 実務への含意

- 配当またぎのアメリカン株式オプションでは、早期行使を単一のBlack-Scholes境界だけで決めない。borrow、税、株式・オプションの実効スプレッド、部分約定も加味する必要がある。
- 市場で観測されるオプション・スプレッドを全て非効率や情報非対称性とみなしてはならない。将来の再ヘッジ費用とworst-case履行資本の対価が含まれる。
- 実装では、価格予測ではなく「askを受けた後に全ノードで資金不足にならないか」というストレステストとして使うと分かりやすい。

## 6. 限界と批判点

1. 二項モデルと既知配当を仮定するため、連続時間のstochastic volatility、離散配当予想の改定、jumpを直接は扱わない。
2. proportional transaction costは、実際の板の深さ、temporary impact、注文優先順位、部分約定を一つのwedgeへ圧縮する。
3. super-replication価格は安全側であり、実際の期待ヘッジ費用や競争的なquoted spreadをそのまま予測するものではない。
4. 保有者の選好に依存する行使区間は重要だが、実際にはcustodianの自動行使、borrow、税、配当受取資格が追加の分岐を作る。
