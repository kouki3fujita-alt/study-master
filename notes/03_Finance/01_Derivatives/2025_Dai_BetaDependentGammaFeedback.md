## 1. 一言でいうと

マーケットメーカーのデルタヘッジが価格変化を増幅するgamma squeezeを、銘柄ごとのbetaで正規化したショック認識と総ガンマ露出を組み合わせてモデル化する理論論文である。中心的な主張は、同じ絶対リターンでも低beta銘柄では「異常なショック」と認識されやすく、適度な価格変化でも強いヘッジ・フィードバックが発生し得る、というもの。

## 2. 問題意識

gamma squeezeでは、オプションを売ったマーケットメーカーがデルタ中立を維持するために原資産を買い増し、その買いがさらに価格を押し上げ、追加ヘッジを誘発する。このメカニズム自体は既存研究でも扱われてきた。

本稿の問題意識は、従来モデルが「同じ価格変化をどの銘柄でも同じように扱いがち」な点にある。例えば、低betaで普段ほとんど動かない銘柄の3%上昇は、市場参加者にとって大きな異常値に見える。一方、高beta銘柄の10%上昇は、その銘柄の通常の変動範囲に近いかもしれない。この相対的な驚きの差が、オプション需要とヘッジ反応の強さを変える。

## 3. 基本モデル

### 3.1 デルタ中立ヘッジ

マーケットメーカーが $N$ 枚のコールを売り、オプション価格を $C(S_t,t)$ とする。一枚あたりデルタは

```math
\Delta_c = \frac{\partial C}{\partial S}
```

であり、総デルタは

```math
\Delta_{\text{total}} = N\Delta_c
```

である。デルタ中立を保つため、マーケットメーカーは概念的に

```math
H_t = N\Delta_c
```

だけ原資産を持つ。原資産価格が変わるとデルタが変わり、その変化はガンマで近似される。

```math
\Delta \Delta_c \approx \Gamma \Delta S
```

したがって、ヘッジ調整量は

```math
\Delta H_t = N\Gamma\Delta S
```

となる。

### 3.2 価格インパクトと古典的なガンマ・フィードバック

価格インパクト係数を $\lambda$、外生ショックを $\mu S_t$、総ガンマ露出を $G=N\Gamma$ とすると、一次近似では

```math
\Delta S_t = \mu S_t + \lambda G \Delta S_t
```

となる。整理すると、

```math
\Delta S_t(1-\lambda G)=\mu S_t
```

である。分母 $1-\lambda G$ がゼロに近づくと、小さな外生ショックが大きく増幅される。

## 4. Beta正規化ショック

本稿の追加要素は、ショックの大きさを銘柄の市場betaと市場ボラティリティで正規化する点である。

```math
x_i =
\frac{|\Delta S/S|}
{|\beta_i|\sigma_m}
```

ここで、$\sigma_m$ は市場全体のボラティリティ、$\beta_i$ は銘柄 $i$ の市場感応度である。$x_i$ は、その銘柄にとって価格変化がどれだけ異常に見えるかを表す。

betaが低い銘柄では、同じリターンでも分母が小さくなり、$x_i$ が大きくなる。したがって、低beta銘柄は、絶対的には小さな価格変化でも、gamma squeezeの初期条件に入りやすい。

## 5. 統合モデルと安定条件

著者は、beta正規化ショックに応じてヘッジ強度が増える関数 $\phi(x)$ を導入する。

```math
\Delta H_t = G \Delta S_t \phi(x)
```

単純な仕様では、

```math
\phi(x)=1+kx
```

と置く。これにより、銘柄 $i$ の安定分母は

```math
D_i = 1-\lambda G\phi(x_i)
```

となる。gamma squeezeの発生条件は、

```math
D_i \rightarrow 0
```

である。つまり、価格インパクト $\lambda$、総ガンマ露出 $G$、beta正規化ショック反応 $\phi(x_i)$ の積が1に近づくと、ヘッジ・フィードバックが不安定化する。

## 6. 再帰的・非線形ダイナミクス

静的な分母条件だけでは、squeezeが時間とともにどう拡大し、どう収束するかは分からない。本稿は、ヘッジ需要、外生ショック、注文到着、累積価格変化による減衰を含む再帰モデルへ拡張する。

主要な直感は次の通りである。

- 初期局面では、ガンマ露出とヘッジ感応度が大きく、価格変化が自己強化される。
- 累積価格変化が進むと、ヘッジ余力やactive gamma exposureが低下し、フィードバックは減衰する。
- 飽和関数を入れると、モデルは無限発散ではなく、急伸後に安定化する bounded nonlinear response になる。
- 確率的な新規オプション注文を入れると、初期局面に二次的な加速が生じ得る。

## 7. シミュレーション結果

シミュレーションでは、betaと総ガンマ露出のグリッド上で安定分母 $D_i$ を描き、$D_i=0$ の境界をgamma squeezeの臨界条件として示す。

主要な含意は以下である。

1. **低beta・高gamma exposureの組み合わせが最も不安定**
   低beta銘柄では、同じ価格変化でも正規化ショックが大きくなるため、$\phi(x_i)$ が上がり、$D_i$ がゼロに近づく。

2. **増幅比が大きい領域は安定境界付近に集中する**
   価格変化の増幅比が2倍を超える領域は、$D_i=0$ の臨界線の近くに現れる。

3. **飽和・減衰はsqueezeを自己制限する**
   ヘッジ限界、gamma exposureの減衰、累積価格変化による抑制を入れると、初期の爆発的増幅後に安定化する。

4. **確率的な注文到着は二次的なripplesを作る**
   追加のオプション需要がランダムに入ると、初期squeezeの途中で短期的な再加速が起きる。

## 8. この論文の貢献

1. 古典的なデルタヘッジ・ガンマフィードバック条件を、beta正規化されたショック認識と結び付けた。
2. $D_i=1-\lambda G\phi(x_i)$ という単純な安定分母で、gamma squeeze発生条件を整理した。
3. 低beta銘柄が、絶対リターンは小さくても相対的ショックとして大きく見えるため、ガンマフィードバックに弱いという直感を形式化した。
4. 静的な価格インパクト式だけでなく、飽和・減衰・確率的注文到着を含む再帰モデルへ拡張した。
5. Amaya et al. (2025)やBaltussen et al. (2021)の実証的なガンマ/ヘッジ需要研究に対し、理論側の簡潔な補助モデルを与える。

## 9. 限界と批判点

1. **実証推定ではない**: 本稿は理論・シミュレーション中心であり、実際のオプション取引データから $\lambda$、$G$、$\phi(x)$ を推定しているわけではない。
2. **betaの扱いが単純**: 単一の市場betaで銘柄固有の通常変動を代表させているが、idiosyncratic volatility、liquidity、short interest、floatなども重要である。
3. **価格インパクト係数が簡略化されている**: 実市場の $\lambda$ は板厚、時間帯、ボラティリティ、注文分割、取引所構造で大きく変わる。
4. **ガンマ露出の内生性**: $G$ や $\Gamma_t$ は価格変化、IV変化、満期接近、注文フローで内生的に変化する。
5. **負beta・複数因子の未処理**: 本文では主に正beta銘柄を想定しており、複数因子モデルやsector betaへの拡張は今後の課題である。
6. **arXiv v1の品質リスク**: 記述に粗い箇所があり、査読済み文献としてではなく、モデル化のアイデアとして扱うのが適切である。

## 10. 実務への含意

- gamma squeezeリスクを見るとき、単にopen interestやgamma exposureを見るだけでなく、その銘柄にとって価格変化がどれほど異常かを正規化して見る必要がある。
- 低beta・低ボラ銘柄で突然のコール需要が発生した場合、絶対リターンが小さくても不安定化条件に近づく可能性がある。
- モニタリング指標としては、推定dealer gamma、板の価格インパクト、銘柄beta、実現ボラティリティ、異常リターンを統合したスコアが有用になり得る。
- 0DTEやmeme stockの議論では、ヘッジ需要の方向だけでなく、銘柄固有の「驚きの尺度」を入れるとリスク判定が改善する可能性がある。

## 11. 次に検討すべき問い

- 実データで $\lambda$、$G$、$\phi(x)$ をどう推定するか。
- OptionMetrics、OPRA、Cboe取引データを使い、$D_i$ に近いsqueeze risk indicatorを作れるか。
- 低beta銘柄ほどgamma squeeze候補になりやすいという予測は、GME/AMC以外のイベントでも成り立つか。
- dealer gammaの符号、short interest、貸株制約、SNSフローを入れると安定条件はどう変わるか。
- Amaya et al. (2025)のOMM集計ガンマ推定やFu et al. (2025)の0DTE注文フロー分析と組み合わせると、実証的なgamma feedbackモデルを構築できるか。

## 12. 総合評価

この論文は、gamma squeezeを厳密な実証結果として示すというより、低beta銘柄における相対的ショック認識をガンマ・ヘッジフィードバックに組み込むための理論メモとして有用である。$D_i=1-\lambda G\phi(x_i)$ という形は単純だが、dealer gamma、流動性、銘柄betaを一つの監視指標にまとめる発想は実務的に使いやすい。既存の0DTE・ディーラーガンマ・meme stock文献と併読することで、短期オプションフローがどの銘柄で不安定化しやすいかを考える補助線になる。
