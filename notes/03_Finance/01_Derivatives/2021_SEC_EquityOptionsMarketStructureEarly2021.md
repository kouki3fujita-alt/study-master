## 1. 一言でいうと

2021年1月のGameStop（GME）を中心とするミーム株の急騰について、SECスタッフがCATなど規制当局しか持たない口座レベルのデータで検証した報告書。結論は「ショートスクイーズは価格上昇の主因ではなく、ガンマスクイーズの証拠はさらに乏しい。数週間にわたる価格上昇を支えたのは強気センチメントそのものである」というものである。また、証券会社が取引を制限した理由はヘッジファンドの圧力ではなく、NSCCによる日中証拠金請求（1月27日に36社へ計69億ドル）への反応であったと整理している。

## 2. 何を明らかにしたいのか

2021年1月、GMEをはじめとする100銘柄超が市場全体を大きく上回る値動きと出来高増加を経験し、複数のリテール証券会社が一時的に売買を制限した。ここから次の問いが公論となった。

1. 価格急騰は**ショートスクイーズ**によるものか。
2. **ガンマスクイーズ**（コール買い→マーケットメーカーの原株ヘッジ買い→株価上昇の自己強化ループ）は起きたか。
3. 100%を超える空売り残高は**裸空売り**の証拠か。
4. 証券会社の売買制限は**ヘッジファンドの圧力**によるものか。
5. 市場構造（PFOF、内部化、注文フローのセグメンテーション、清算・決済）はこの事象でどう機能したか。

本報告書の価値は、これらの問いに対して**一般には入手できない口座レベルデータ**（CAT、NSCC、MIDAS）を当てられる点にある。逆に言えば、そこが再現不可能性という最大の弱点でもある。

## 3. 制度的背景（第2章の要点）

学術論文における「モデル」に相当する部分が、本報告書では制度説明である。以下は結果の解釈に直結する。

### 3.1 株式と上場オプションの構造的な違い

| 項目 | 株式（NMS株） | 上場標準化オプション |
|---|---|---|
| 上場・取引の場 | 16の全国証券取引所＋34のATS＋場外マーケットメーカー | 全国証券取引所のみ |
| 銘柄・系列数 | NMS株 10,000超 | オプション系列 1,000,000超 |
| 気配の主な出し手 | 指値注文＋マーケットメーカー | 主にマーケットメーカーの気配 |
| 決済 | T+2 | T+1 |
| 取引所での執行比率 | 全体の60%未満 | ほぼ全量が取引所執行 |

オプション系列が100万を超えるため、任意の系列に投資家の指値が板に残っている可能性が低く、**価格はマーケットメーカーの気配で決まる**。これがオプションIVが需給圧力に敏感になる構造的理由である。

### 3.2 場外マーケットメーカーとセグメンテーション

- 株式では、リテール証券会社の注文は場外マーケットメーカー（ホールセラー）に回送され、**内部化**（相手方として自己勘定で執行）される。
- オプションでは、場外マーケットメーカーは「**コンソリデーター**」として個人のオプション注文フローを買うが、OCCが原則として取引所で成立した取引しか清算しないため、場外執行はできない。どの取引所で執行するかを選ぶ（自社または関連会社が相手方になりやすい取引所を選ぶ余地がある）。
- セグメンテーションの経済的理由は**逆選択の回避**である。情報を持たない小口・非相関・「one and done」の注文は将来価格との相関が低く、狭いスプレッドを提示できる。
- その対価としてPFOF（payment for order flow）が支払われる。これはリテール証券会社に利益相反を生む。脚注28・42はRobinhood命令を引き、同社が価格改善とPFOFの価値を**おおむね20/80で分配**し、他社が受けていた典型的な80/20より自社取り分が大幅に大きかったと指摘している。
- オプション市場ではPFOFが株式市場より広く行われている可能性がある、と本文が述べている点は重要である。

### 3.3 NBBOの限界

本報告書は、NBBOを執行品質のベンチマークとすることの限界を明示している。NBBOは場外流動性や端株（odd lot）・非表示注文といった良い気配を含まないため、**NBBO基準の価格改善統計は実際の価格改善を過大評価しうる**。

### 3.4 清算・証拠金の仕組み

- NSCC（DTCCの子会社）は清算基金（Clearing Fund）を維持する。所要額の最大部分は**ボラティリティ・コンポーネント**で、パラメトリックVaRモデルにより一定期間の将来リスクを**99パーセンタイル**の信頼水準で推計する。
- NSCCは日中の値洗い請求に加え、特定銘柄に異常なボラティリティを観測した場合の**特別チャージ**を課しうる。
- **ECP（excess capital premium）チャージ**は、清算ポジションの証拠金エクスポージャーが会員の超過純資本を上回る場合に課される。「一日の活動に基づく著しい一時的増加へ対応するもの」と位置づけられている。
- OCCは16の参加オプション取引所の清算機関である。

## 4. データと実証設計

### 4.1 使用データ

- **Consolidated Audit Trail（CAT）**: 口座タイプ別・FDID（Firm Designated ID）別の注文・約定データ。GME関連の口座数、個人顧客比率、内部化の帰属、空売り主体の買い戻し分析の中核。**CATのサンプルは2020年12月24日から始まる**。
- **NSCC提供データ**: 証拠金請求、フェイル、XRTの償還。
- **MIDAS / Consolidated Quote System / 取引所プロプライエタリ・フィード**: スプレッド、板の厚み。
- **NYSE TAQ**: 出来高、LULD発動回数、価値加重平均株価。
- **Compustat North America Supplemental Short Interest File**、**CRSP日次株式ファイル**: 空売り残高比率の算出。
- **Bloomberg、ORTEX**: ETFスプレッド、貸株料。
- 定義: 本報告書の「individual investor」は、証券会社の推奨によらない自己判断（self-directed）の自然人を指す。CATの “individual customer account”（FINRA Rule 4512(c)の「機関」＝総資産5,000万ドル以上の銀行・投資顧問等に該当せず、自己勘定でもない口座）とは定義が異なる。

### 4.2 実証設計と限界

**本報告書に回帰分析は一切ない。** 記述統計、時系列図、イベント前後比較のみである。以下は数式で表される「モデル」ではないが、スタッフが実質的に検証している識別ロジックである。

**ショートスクイーズ仮説の検証**（Figure 6）

1. 2021年1月15日時点の各トレーダーの平均インベントリーを計算する。
2. マーケットメーカーと高頻度トレーダー（日中に反対売買で相殺する主体）を除外し、平均ポジションが負のFDIDを抽出する。
3. その中でインベントリーが**中央値より負**のFDIDを「大口ショート勢」と定義する。
4. これらのFDIDが1月19日〜2月5日に開始した買い注文を、30分刻みの総買い出来高・価値加重平均株価と重ねる。

判定基準は「大口ショート勢の買いが**総買い出来高に占める割合**」と「買い戻し効果が薄れた後も高値が続いたか」である。

**ガンマスクイーズ仮説の検証**

ガンマスクイーズが成立するには、(a) コールの買い越しが急増し、(b) マーケットメーカーがそのコールを**書いて**原株を買いヘッジする、という二条件が必要になる。スタッフは(a)(b)の両方をCATで直接確認しにいった。

**注意**: この設計の弱点は明白で、CATが2020年12月24日開始のため、それ以前に積み上がったポジションが観測できない。報告書自身が脚注78で「CATサンプルが2020年12月24日開始のため、それ以前のFDIDのインベントリー・ポジションを含められない」と明記している。GMEの空売りは2019年から積み上がっていたので、これは重大な制約である。

## 5. 主要結果

### 5.1 株式市場での価格・出来高の推移（第3.2節）

| 時点 | 事実 |
|---|---|
| 2020年初 | 1株6ドル強 |
| 2020年4月 | 50%下落し3ドル未満 |
| 2020年8月31日 | Ryan Cohen（Chewy共同創業者）の出資開示。前日終値6.68ドルから**+23.93%**、出来高3,800万株（前日比+3,400万株） |
| 2020年通年 | 平均日次出来高**約670万株**、日次終値リターンの標準偏差**7.46%** |
| 2020年末 | 20ドルをやや下回る水準 |
| 2021年1月11日 | Cohenの取締役就任発表。日中高値**20.65ドル**（前日終値比約+17%） |
| 2021年1月13日 | 終値19.95ドル → **31.40ドル**、出来高約700万株 → **約1億4,400万株** |
| 2021年1月22日 | 約3時間で43ドル → 72ドル（**+71%**）。月内最大出来高**1億9,720万株** |
| 2021年1月27日 | 終値**347.51ドル**（1月11日終値比 **+1,600%超**） |
| 2021年1月28日 | 日中高値**483.00ドル** |
| 2021年1月13〜29日 | 平均日次出来高約1億株（2020年平均比 **+1,400%超**） |

- 1月8日の日中安値から1月28日の日中高値まで、**日中株価は約2,700%上昇**し、その後2月第1週末の終値まで**86%超下落**した。
- 日次終値の変化幅は、1月26日→27日で**+199.53ドル**、1月27日→28日で**−153.91ドル**。
- GME売買口座数（CAT）は、月初の1万口座未満から1月27日には**約90万口座**へ増加。1月13日には前日9,220口座から**60,515口座**へ6倍超に増えた。

**重要な相対化**: GMEの値動きは2021年1月として例外的ではなかった。1月26日終値比の1月27日単日騰落率は、KOSS **480.0%**、AMC **301.2%**、NAKD **252.3%**、EXPR **214.1%** で、いずれもGMEのどの単日変化率よりも大きい。さらに2020年以降、**134の普通株**がGMEの最大単日上昇率を上回る単日上昇を少なくとも1回経験している。

### 5.2 空売り（第3.4節）

- 2021年1月のGME空売り残高（**浮動株比**）は**122.97%**。他のミーム株はDDS 77.3%、BBBY 66.02%、FIZZ 62.59%、AMC 11.4%、NAKD 7.3%、KOSS **0.92%**。**KOSSは空売り残高がほぼゼロなのに単日480%上昇している**。これ自体がショートスクイーズ説への強い反証である。
- **発行済株式数比**では、GMEは2020年12月31日に**109.26%**の高値を付けた。2020年を通じて約100%前後で推移していた。
- 100%超が生じる理由は裸空売りではなく、**同一株の再貸出**である。空売り株を買った投資家がその株をさらに貸し出すと、同じ1株が二重に空売りとしてカウントされる。
- 空売り残高比率の水準感: 大型非金融株では2.5%未満、小型非金融株でも13%未満が通例。50%超はほとんど存在しない（2008年の市場混乱時でも、単一の記録日に50%超だったのは**12銘柄**）。90%超は2007年と2008年に数回観測されただけである。**発行済株式数を超える空売り残高が観測されたのは、2021年1月ではGMEのみ**。

**結論（本報告書の中核）**

> 1月22日から27日にかけて、空売り残高が減少するなかで株価が上昇した局面があり、大口ショート勢の買い戻しが価格上昇に寄与した可能性が高い。しかし、**その買いは総買い出来高のごく一部にすぎず**、買い戻しの直接的効果が薄れたあとも高値が続いた。数週間に及ぶ価格上昇を支えたのは、買い戻しではなく**ポジティブ・センチメント**である。

### 5.3 ガンマスクイーズは確認されなかった（第3.4節）

個人顧客口座のGMEオプション売買代金は次のように急増した。

- 1月21日: **5,850万ドル**
- 1月22日: **5億6,340万ドル**
- 1月27日（ピーク）: **24億ドル**

しかしスタッフの判定は否定的である。理由は二つ。

1. この増加は**コールではなくプットの買い**が主導した。
2. データ上、**マーケットメーカーはコールを書くのではなく買っていた**。

ガンマスクイーズが成立するには、マーケットメーカーがコールの売り手となり原株を買いヘッジする必要がある。観測されたのはその逆であった。したがって「これら自体はガンマスクイーズと整合的でない」と結論している。

**注意（本ノートの解釈上の重要点）**: 5.6節で見るとおり、**売買代金ベースではコール、特に短期コールに集中していた**と第3.9節は述べている。第3.4節の「プット買い主導」は**個人顧客口座のオプション売買代金の増加分**についての記述であり、対象母集団と期間が異なる。両者を同じ文として引用してはならない。

### 5.4 裸空売りとフェイル（第3.4節）

- GMEでフェイル・トゥ・デリバー（受渡失敗）のスパイクは観測された。
- ただしフェイルは空売りでも通常売却でも生じるため、裸空売りの完全な代理変数にはならない。
- **清算会員レベルでは持続的なフェイルは生じていない**。ほとんどの清算会員は数日以内にフェイルを解消し、複数日にまたがるフェイルは概ね発生しなかった（NSCC提供データによる分析）。

### 5.5 ETFへの波及（第3.3節）

| ETF | GME組入比率 | スプレッド（3日平均 vs 52週平均） |
|---|---|---|
| XRT（SPDR S&P Retail） | 1.5%（2020/12/31）→ **19.98%**（2021/1/27） | **0.073ドル** vs 0.011ドル |
| GAMR（Wedbush ETFMG Video Game Tech） | 2.04%（2020/12/31）→ 最大**17%**（2021/1/28） | **1.32ドル** vs 0.186ドル |

- XRTは修正等ウェイト指数を追跡し、この期間リバランスしなかったため、GME株価上昇に伴い組入比率が機械的に膨らんだ。
- 1月27日、XRTは**5億600万ドル**の純償還を経験。これは純資産の**76.3%**にあたり、同ファンド史上2番目の規模。株数ベースでは**約600万株**の純償還。
- この償還はほぼ全量がETFマーケットメイク業者によるもので、投資家のXRT売り（空売りを含む）を受けたマーケットメーカーが、相殺せずに現物バスケットへ償還した結果と解釈されている。XRTの空売り残高は発行済株式数の数倍あり、**XRTの空売りがGMEの間接的な空売り手段**として使われた可能性がある。
- それでも1月28日のXRT終値のNAVプレミアムは**1.25%**にとどまった。過去の平常水準よりは大きいが、設定・交換プロセスの機能不全を示すものではない。**裁定機構は機能していた**というのがスタッフの評価である。

### 5.6 貸株コスト（第3.4節）

- 2020年第2四半期のGME借株コストは**100%超**（極めて異常な水準）。2020年6月までに50%未満へ低下。2021年1月は**約25%**で、2月にかけて空売り残高の減少とともに低下。
- 比較基準: 2007年1月〜2018年7月において、貸株料が100%を超えたことのある銘柄は**222社のみ**で、全観測の**0.01%**にすぎない。同期間の平均貸株料は**1.5%**。
- スタッフはHarrison and Kreps (1978) を引き、空売り制約がファンダメンタルズを超える価格上昇（バブル）に寄与しうるという学術的知見に言及している。**「ショートスクイーズが主因ではない」という結論と、「空売りの高コスト・高リスクが上昇に寄与した可能性」は矛盾しない**点に注意が必要である。

### 5.7 清算機関の証拠金と証券会社の取引制限（第3.5・3.6節）

**2021年1月27日のNSCC**

- **36の清算会員**に対し、日中証拠金請求を実施。合計**69億ドル**。
- 全会員の所要証拠金合計は**255億ドル**に達した。
- 69億ドルの内訳: **21億ドル**が日中の値洗い請求、**48億ドル**が特別ECPチャージ。
- 特別チャージは**18会員**に課され、全社が追加証拠金を差し入れた。もう1社は関連会社からの移管でエクスポージャーを相殺し、最終的に支払わずに済んだ。
- 1月28日、NSCCは規則に基づく裁量でECPチャージを**全会員について免除**した。理由は、超過リスク／資本比率の悪化が個々の会員の行動ではなく個別株の極端なボラティリティに起因したためである。
- **この免除がなければ、あるリテール証券会社は1月28日の所要証拠金14億ドルの2倍超に相当する追加ECPチャージを負っていた。**
- 免除は2月2日に解除された。
- OCCの証拠金所要額もNSCCと同様のパターンをたどったが、OCCはこの期間に財務資源を増やす非通常の措置を取っていない。
- NSCCとOCCはいずれも2021年1月27日に**過去最高の清算量**を記録した。
- NSCCは他の中央清算機関と同様、個別銘柄の取引・清算停止を会員に指示する権限を規則上持たない。**取引制限は証券会社自身の判断であり、NSCCの指示ではない。**

**ある証券会社の実際の動き（第3.6節）**

## 6. 数式について

本報告書に導出された数式はない。定量的な定義として明示的に述べられているのは以下である。

**空売り残高比率（short interest ratio）**

$$
SIR_{i,t}=\frac{\text{空売り株数}_{i,t}}{\text{発行済株式数}_{i,t}}
$$

Figure 5では、空売り株数はCompustat North America Supplemental Short Interest File（NYSE・Nasdaq上場銘柄）から隔週で取得し、発行済株式数はCRSP日次株式ファイルから取得する。空売り残高は決済日基準で報告されるため、**報告日の2営業日前の取引日**にマッチさせる。標本は非金融（SICコード6000〜6999を除外）の普通株（CRSP share code 10または11）。Blocher and Ringgenberg (2019) に従い、空売り残高比率と調整後空売り残高比率（株式分割・自社株買い等で調整）が10%超乖離する銘柄を除外する。比較対象グループについては、記録日2営業日前の終値×発行済株式数を時価総額ウェイトとする価値加重平均を取る。

なお本文中では、同じ「短期残高比率」という語が**浮動株比**（122.97%）と**発行済株式数比**（109.26%）の二通りの分母で使われている。**引用時は必ず分母を明示すること。**

**LULDの発動条件**

参照価格（直近5分間の報告取引の算術平均）に対して一定率で上下バンドを設定し、National Best Bidが上限に、またはNational Best Offerが下限に**15秒間**一致した場合、**5分間**の取引停止を行う。バンド幅は銘柄種別・株価水準・時間帯で異なる。

**証拠金**

- 当初証拠金: Regulation Tにより、顧客は購入代金の50%超を借入で賄えない。
- 維持証拠金: FINRA Rule 4210(c)により、口座は最低25%のエクイティを維持する。
- NSCCのボラティリティ・コンポーネント: **99パーセンタイル**の信頼水準のパラメトリックVaR。

## 7. 解釈上の注意、限界、批判点

1. **査読を経ていない政府スタッフ文書である。** 冒頭のDISCLAIMERが明示するとおり、委員会の見解ではなく法的効力もない。学術論文と同列に扱ってはならない。
2. **回帰も統計的検定も存在しない。** 「ショートスクイーズは主因ではない」という結論は、Figure 6の視覚的比較と記述統計に基づく判断であり、有意水準を伴う推定ではない。反証可能な形で定量化されていない。
3. **CATが2020年12月24日開始という制約。** GMEの空売り残高は2019年から積み上がっていたが、それ以前のインベントリーを観測できない。したがって「大口ショート勢」の特定はサンプル期間内の平均ポジションに依存し、**実際の空売り主体を取りこぼしている可能性がある**。これは本報告書自身が脚注78で認めている。
4. **再現不可能性。** CAT、NSCC、MIDASはいずれも一般に非公開であり、外部研究者は本報告書の中核的な主張を検証できない。これは学術的な基準では致命的な弱点である。反面、それこそが規制当局にしか書けない報告である理由でもある。
5. **匿名化による検証困難。** 第3.6節で分析される証券会社は「one broker-dealer」としか記載されない。記述はRobinhoodと整合的に読めるが、報告書自体は名指しを避けている。
6. **「ガンマスクイーズなし」の射程。** 否定されているのは「マーケットメーカーがコールを書いて原株を買いヘッジしたことで自己強化的な上昇が生じた」という特定の機序である。オプション市場が株価に何ら影響しなかったという主張ではない。実際、IVは2020年通常レンジの9倍まで上がり、オプション売買代金は80億ドルに達している。
7. **プット買い主導とコール集中の両立。** 5.3節で述べたとおり、第3.4節の「増加分はプット買いが主導」と第3.9節の「売買代金はコール、特に短期に集中」は、対象母集団（個人顧客口座の増加分 vs 全体の売買代金）が異なる記述である。**この二つを無批判に並べると相互矛盾に見える**ため、引用時は文脈を分けること。
8. **因果推論としての弱さ。** 「価格上昇を支えたのはポジティブ・センチメントである」という結論は、他の候補（買い戻し、ガンマスクイーズ）を消去した**残余的な説明**であり、センチメントを直接測定したものではない。センチメント指標も、Reddit投稿数などの定量分析も本報告書には含まれない。
9. **時期の限定。** 分析対象は2021年1〜2月に限られる。2021年後半以降のミーム株、0DTEオプションの拡大、2024年のT+1移行後の環境へそのまま外挿できない。
10. **XRTのNAVプレミアム1.25%の評価。** スタッフは「創設・償還プロセスの機能不全を示すものではない」と評価するが、この判断の閾値は示されていない。

## 8. 実務的含意

- **IVサーフェスの読み方**: 50デルタIVが平常レンジの9倍という水準は、期待ボラティリティ、テールの厚み、需給圧力、マーケットメーカーの在庫・資本制約が混在した数値である。脚注118はこれを明示的に警告している。同じ論点は Eaton et al. (2026) が識別戦略を伴って検証している。
- **オプション市場のマーケットメイク**: オプション系列が100万超あるため、価格は板の指値ではなくマーケットメーカーの気配で決まる。単一銘柄オプションのIVは、そのためフローの影響を受けやすい。
- **執行品質の測定**: NBBOを基準とした価格改善統計は、端株・非表示注文・場外流動性を含まないため過大評価になりうる。リテール執行品質の評価では代替ベンチマークが必要である。
- **清算リスクの伝播経路**: 「NSCCの証拠金 → 清算ブローカーの流動性 → リテール証券会社の取引制限 → 顧客が売買できない」という連鎖が実際に起きた。この経路は、資本の薄い証券会社ほど短絡しやすい。決済サイクル短縮（T+2 → T+1）がその緩和策として本報告書で提案された。
- **リスク管理の設計**: 一日の活動に基づくECPチャージが所要証拠金の2倍超に達しうるという事実は、ストレステストの設計上重要である。裁量的な免除に依存する構造そのものがリスクである。
- **相関の集中管理**: 均等ウェイトETFは、構成銘柄の急騰でリバランスしない限り比率が機械的に膨らむ。XRTでは1.5%が19.98%になった。ETFを「分散された」エクスポージャーと前提するのは危険である。
- **空売り残高の解釈**: 100%超の空売り残高は裸空売りの証拠ではなく、再貸出の帰結である。この誤解は現在も広く残っている。

## 9. 本報告書が提起した4つの検討課題（第4章）

1. **証券会社に取引制限をもたらしうる力**。清算機関の日中証拠金請求が、資本の薄い証券会社に与える影響。緩和策として**決済サイクルの短縮**が挙げられている。
2. **デジタル・エンゲージメント慣行とPFOF**。ゲーム的機能や祝賀アニメーションが取引を増やしていないか。PFOFのインセンティブが、証券会社に顧客の取引量を増やす新たな手法を促していないか。
3. **ダークプールとホールセラーでの取引**。GMEのリテール注文フローの大部分は場外で執行され、市場全体からは見えにくい。ホールセラーは取引所やATSに比べ、運営の透明性・レジリエンスに関する要件が緩い。
4. **空売りと市場ダイナミクス**。空売り報告の改善により、当局がこれらの動態をより良く追跡できるようにすべきである。

**その後の展開（本報告書以降の文脈。報告書外の情報であり、本報告書の記述ではない）**

- 2. のDEPについては、本報告書と同時期にRelease No. 34-92766（File No. S7-10-21、2021年8月27日）として情報提供要請が出されている。これは本報告書の脚注15で言及されている。

## 11. 総合評価

本報告書の最大の価値は、**規制当局しか持たない口座レベルのデータで、当時支配的だった二つの物語（ショートスクイーズ、ガンマスクイーズ）を検証した点**にある。とくにガンマスクイーズについて「マーケットメーカーはコールを書くのではなく買っていた」という直接的な観測を示したこと、KOSSの空売り残高が0.92%でありながら単日480%上昇したという反例を提示したことは、公開データでは到達しにくい。

一方、学術文献としての厳密さは持たない。回帰も検定も反事実も存在せず、「ポジティブ・センチメントが上昇を支えた」という中心的結論は他説の消去による残余的説明にとどまる。再現も不可能である。

したがって本報告書の適切な使い方は、**因果的主張の根拠としてではなく、(a) 当該期間の事実関係と数値の一次資料として、(b) 米国株式・オプション市場構造の制度解説として、(c) その後の規制動向（DEP、空売り報告、T+1）の起点として**引用することである。市場マイクロストラクチャーの実証研究においては、CATベースの記述統計を「当局が観測した事実」として扱い、そこから外生ショックを用いた識別デザインへ接続するのが妥当な位置づけになる。
